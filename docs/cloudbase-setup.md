## 1. 打开当前工程

微信开发者工具导入 `/Users/zaza/work/xinxin-decoration`。项目配置已包含：

- 小程序目录：`miniprogram/`
- 云函数目录：`cloudfunctions/`
- 编译插件：TypeScript
- 默认页面：`pages/index/index`

点击“编译”，应能看到鑫新装饰的“开发环境准备”页面。若工具未更新目录配置，关闭并重新打开当前项目。

## 2. 开通环境

1. 点击开发者工具上方的“云开发”。
2. 按提示完成管理员授权与服务开通。
3. 本项目已创建名称为 `cloud1` 的开发环境，可以直接使用，不需要重新创建或改名。
4. 如需选择地域，优先上海；数据库使用文档型数据库。
5. 优先使用开通页面提供的开发免费/体验环境，具体费用、限制和有效期以界面为准。
6. 等待初始化完成，在环境设置中复制完整“环境 ID”。

从微信开发者工具创建的环境会自动关联当前小程序。首次开通只需一个开发环境，生产环境在上线前单独创建。

## 3. 填写环境 ID

修改 `miniprogram/config/cloud.ts`：

```ts
export const cloudConfig = {
  envId: 'cloud1-d8g6md4r9e96e1f14',
};
```

当前已填好。这里填写平台生成的环境 ID，而不是环境名称 `cloud1`。留空时不会初始化或调用默认环境。

## 4. 部署联调云函数

1. 在开发者工具文件树找到 `cloudfunctions/`。
2. 若右键菜单存在“当前环境”，选择 `cloud1`，核对完整环境 ID 为 `cloud1-d8g6md4r9e96e1f14`。
3. 右键 `healthcheck` 目录。
4. 点击“上传并部署：云端安装依赖”（具体名称以工具为准）。
5. 确认云开发控制台的云函数列表出现 `healthcheck`。

云函数依赖由平台安装，初次联调不需要在本机安装 Node.js、CLI 或 npm 包。

## 5. 验证

重新编译，点击“检查云函数连接”。成功后显示“云函数连接成功”。

本检查验证：

- 指定环境中的 `healthcheck` 能被小程序调用；
- 云函数取得当前小程序的 AppID 和微信身份；
- 返回值通过小程序调用链路读取。

本检查不会验证数据库读写、文件上传权限或 AI 模型可用性；这些能力在后续各自进行联调。

若失败，依次确认完整环境 ID、开发者微信权限、环境关联，以及函数部署的目标环境。私有项目数据权限和 AI 调用将在业务开发时配置。
