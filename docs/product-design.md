# 鑫新装饰微信小程序产品设计方案

> 文档版本：V0.1  
> 更新日期：2026-10-13  
> 产品阶段：首版方案 / 快速原型

相关技术方案：[技术设计与实施方案](./technical-design-and-implementation.md)

## 1. 产品概述

### 1.1 产品定位

鑫新装饰微信小程序是一款面向本地装修客户的业务展示与辅助成交工具。小程序通过业务介绍、成功案例和店铺联系方式吸引潜在客户；在线下量房后，由工程师上传现场资料并生成多角度 AI 效果预览，经人工审核后以专属链接分享给客户。

AI 效果图用于降低客户理解方案的难度、提升沟通效率，不替代工程设计、施工图和最终交付承诺。

### 1.2 核心目标

1. 清晰展示鑫新装饰的业务范围、工艺能力和真实案例。
2. 引导客户通过微信或电话直接咨询。
3. 将“一套房、多个安装位置、多种产品组合”的线下方案数字化。
4. 通过多张、多角度 AI 效果图辅助客户理解和确认方案。
5. 在不部署独立服务器的前提下，使用微信云开发完成数据、文件、权限和 AI 调用。

### 1.3 成功标准

- 顾客能在 1 分钟内理解主营业务并找到咨询入口。
- 工程师能按项目和安装位置完整录入现场资料与客户要求。
- 未经工程师审核的 AI 图片不能被客户访问或分享。
- 客户通过一个专属链接即可浏览整套项目及各位置的多角度预览。
- 首版保持低维护成本，不引入独立服务器和复杂客户账户体系。

## 2. 用户与权限

### 2.1 普通访客

- 浏览首页、业务分类、工艺说明和成功案例。
- 查看店铺电话、微信二维码和地址。
- 拨打电话或添加微信进行咨询。
- 通过有效的专属链接查看指定项目效果预览。
- 不能创建项目、上传资料或调用 AI。

### 2.2 工程师/管理员

- 通过微信身份和后台白名单验证身份。
- 创建、编辑和归档项目。
- 为项目添加多个安装位置与产品组合。
- 上传现场照片、结构简图、材质参考图等资料。
- 录入尺寸、材料、颜色、表面处理和客户要求。
- 创建多角度 AI 生成任务，查看进度、失败原因和结果。
- 重新生成、驳回或确认效果图。
- 仅对审核通过的结果生成专属分享链接。

### 2.3 专属链接访问者

- 不需要建立完整客户账户。
- 通过项目分享码访问指定内容。
- 先查看项目概览，再按安装位置和角度浏览效果图。
- 不可查看原始现场资料、工程师备注、生成提示词或未审核图片。

## 3. 产品原则

1. **项目优先：** 一套房或一个工程为一个项目，而不是把单个门窗当作订单主体。
2. **位置组织：** 项目按阳台、卧室窗、入户门、雨棚等安装位置组织内容。
3. **组合产品：** 一个安装位置可包含门、窗、护栏、雨棚等多个产品。
4. **先审核再分享：** AI 输出默认仅工程师可见，审核后才进入客户页面。
5. **直接沟通：** 首版不建设留资表单，使用微信和电话完成转化。
6. **明确边界：** 效果图必须显示 AI 预览标识和施工结果免责声明。
7. **轻量部署：** 优先使用小程序原生能力和微信云开发，降低运维复杂度。

## 4. 首版范围

### 4.1 顾客端

- 首页与品牌/店铺介绍
- 主营业务分类与业务详情
- 工艺、材料和可定制能力介绍
- 成功案例列表与详情
- 电话、微信二维码、店铺地址
- 专属项目效果预览
- 小程序页面分享

### 4.2 工程师端

- 工程师身份验证
- 项目列表和项目状态筛选
- 项目创建、编辑、归档
- 安装位置及产品组合管理
- 现场照片、结构简图、材质参考图上传
- 尺寸、材料、材质、颜色、表面处理和文字要求录入
- 多角度 AI 生成任务
- 生成进度、失败与重试
- 效果图审核和确认
- 专属分享链接创建、停用和失效时间设置

### 4.3 首版不包含

- 在线报价、自动算价和合同签署
- 在线预约表单
- 支付、下单和物流
- 普通顾客自主调用 AI
- 复杂客户账户中心
- 可直接施工的工程图或尺寸校验
- AI 效果视频生成

效果视频可作为后续能力：以已审核的多角度图片作为输入，生成视频后继续执行人工审核和专属分享流程。

## 5. 信息架构

### 5.1 顾客端底部导航

| 导航 | 页面内容 | 主要动作 |
| --- | --- | --- |
| 首页 | 品牌主张、业务入口、精选案例、服务流程 | 查看业务、查看案例、联系店铺 |
| 业务 | 产品/服务分类、材料与工艺说明 | 查看详情、电话咨询 |
| 案例 | 项目案例列表、案例详情 | 浏览图片、咨询同类方案 |
| 联系 | 电话、微信二维码、地址和营业信息 | 拨打电话、复制微信号 |

专属项目预览不放在公共导航中，只能通过有效分享链接进入。

### 5.2 工程师工作台

| 页面 | 核心内容 |
| --- | --- |
| 项目列表 | 项目名称、客户称呼、小区、状态、更新时间 |
| 项目详情 | 基本信息、安装位置、资料完整度、生成状态 |
| 安装位置编辑 | 空间位置、尺寸、产品组合、材料要求、备注 |
| 资料上传 | 现场照片、结构简图、材质和颜色参考 |
| AI 生成 | 选择位置、角度、生成数量，确认提示词摘要 |
| 效果审核 | 原始参考与生成结果对照、确认、驳回、重试 |
| 分享设置 | 分享范围、有效期、启用状态、分享入口 |

## 6. 关键用户流程

### 6.1 获客流程

```text
顾客进入小程序
→ 浏览业务或成功案例
→ 查看联系方式
→ 添加微信或拨打电话
→ 线下沟通与预约上门
```

### 6.2 工程师生成流程

```text
创建项目
→ 添加安装位置
→ 选择每个位置的产品组合
→ 上传现场照片/结构简图/材质参考
→ 填写尺寸、材质、颜色和客户要求
→ 选择需要生成的角度
→ 创建 AI 任务
→ 查看多张生成结果
→ 工程师审核或重新生成
→ 确认可分享图片
→ 创建专属分享链接
```

### 6.3 客户查看流程

```text
打开工程师分享链接
→ 查看项目概览和免责声明
→ 选择安装位置
→ 切换不同角度效果图
→ 查看材料与方案摘要
→ 联系工程师继续确认
```

## 7. 项目与 AI 生成模型

### 7.1 项目层级

```text
项目 Project
├── 基本信息
├── 安装位置 Location A
│   ├── 产品组合
│   ├── 尺寸与材料要求
│   ├── 现场资料
│   └── 多角度效果图
├── 安装位置 Location B
│   └── ...
└── 分享设置
```

### 7.2 AI 输入要求

每个安装位置至少应支持以下信息：

- 现场全景照片和必要的局部照片
- 工程师结构简图
- 长、宽、高及其他关键尺寸
- 产品组合，例如“推拉窗 + 防护栏”
- 主材与规格，例如 304 不锈钢、铝合金型材
- 表面处理，例如拉丝、镜面、喷涂
- 颜色和材质参考图
- 客户的样式、采光、通风、安全等要求
- 需要生成的观察角度
- 工程师补充说明和禁止改变的结构要点

### 7.3 多角度生成

一个位置的一次生成批次包含多个独立角度任务，例如：

- 正面整体
- 左侧斜视
- 右侧斜视
- 室内向外
- 室外向内
- 关键连接部位近景

同一批次应共享项目、位置、产品组合和材质要求。系统记录每张图对应的视角、模型、生成参数和审核状态，方便重试和追溯。

### 7.4 审核状态

```text
草稿 → 排队中 → 生成中 → 待审核 → 已确认 → 已分享
                       └→ 生成失败
                       └→ 已驳回 → 重新生成
```

### 7.5 免责声明

客户预览页及每张大图查看页均显示：

> AI 效果预览图，仅用于方案沟通与展示；颜色、材质、比例及细节可能存在偏差，最终结果以实际施工和安装效果为准。

图片建议同时增加“AI 效果预览”可见标识。

## 8. 云开发技术方案

### 8.1 总体架构

```text
微信小程序
├── 顾客端页面
├── 专属项目预览
└── 工程师工作台
        │
        ▼
微信云开发
├── 云数据库
├── 云存储
├── 云函数
└── CloudBase AI / 腾讯云 AI 生图服务
```

首版不部署独立服务器。AI 密钥、模型调用、权限检查和分享链接解析全部放在云函数中，不能暴露在小程序前端。

### 8.2 数据集合建议

| 集合 | 用途 | 关键字段 |
| --- | --- | --- |
| `users` | 工程师和管理员 | `openid`、姓名、角色、状态 |
| `store_config` | 店铺公共信息 | 电话、微信号、二维码、地址 |
| `service_categories` | 业务分类 | 名称、封面、排序、启用状态 |
| `cases` | 成功案例 | 标题、小区、分类、图片、说明 |
| `projects` | 工程项目 | 项目名、客户称呼、小区、状态 |
| `project_locations` | 安装位置 | 项目 ID、位置名、产品组合、要求 |
| `source_assets` | 原始资料 | 文件 ID、类型、项目/位置 ID |
| `generation_batches` | 一次多角度生成批次 | 位置 ID、输入摘要、状态 |
| `generation_jobs` | 单角度 AI 任务 | 角度、模型、状态、错误信息 |
| `render_assets` | AI 效果结果 | 文件 ID、角度、审核状态 |
| `share_links` | 专属分享 | 分享码、项目 ID、有效期、状态 |

### 8.3 云存储目录建议

```text
public/services/
public/cases/
private/projects/{projectId}/source/
private/projects/{projectId}/locations/{locationId}/
private/projects/{projectId}/renders/{batchId}/
private/projects/{projectId}/videos/
```

原始资料和未审核结果必须保持私有，只能通过云函数进行授权访问。

### 8.4 云函数建议

- `authEngineer`：验证工程师身份
- `createProject` / `updateProject`：项目写入和权限检查
- `createGenerationBatch`：整理输入并创建多角度任务
- `queryGenerationBatch`：同步异步任务状态
- `saveGenerationResult`：将临时结果转存云存储
- `reviewRender`：确认、驳回或重试效果图
- `createShareLink`：创建受控项目分享码
- `getSharedProject`：仅返回审核通过的客户可见数据
- `disableShareLink`：立即停用分享

### 8.5 权限边界

- 公共业务和案例只允许读取已发布内容。
- 工程师写操作必须同时校验登录身份和白名单角色。
- 普通访客不能直接查询项目集合。
- 专属项目通过云函数解析分享码，返回最小必要字段。
- 未审核图片、原始现场资料、尺寸和工程师内部备注不得出现在分享接口中。
- AI 密钥及腾讯云访问密钥只存储在服务端安全配置中。

## 9. 页面视觉方向

### 9.1 设计关键词

- 可靠
- 扎实工艺
- 本地服务
- 金属质感
- 清晰直接

### 9.2 建议风格

- 主色使用深石墨灰，体现不锈钢和工程属性。
- 强调色使用暖橙或铜色，用于咨询、审核和关键操作。
- 大图优先展示真实案例，避免过多装饰性图形。
- 卡片信息重点显示“安装位置 + 产品组合 + 材质”。
- 顾客端文案通俗，工程师端字段明确、状态清晰。

## 10. 原型覆盖范围

快速原型重点验证：

1. 顾客首页能否快速理解主营业务并找到联系方式。
2. 成功案例是否以“整套项目”而不是单个产品呈现。
3. 专属链接是否能清楚展示项目、安装位置和多角度图片。
4. 工程师是否能理解“项目 → 安装位置 → 资料 → 多角度生成 → 审核 → 分享”的操作顺序。

原型为交互与信息结构验证版本，不代表最终视觉稿，也不包含真实 AI 调用和数据库连接。

## 11. 首版验收标准

- 公共内容无需登录即可浏览。
- 电话按钮可唤起拨号；微信信息易于复制或扫码。
- 工程师以项目为单位维护多个安装位置和产品组合。
- 每个安装位置可上传多类资料并记录材质要求。
- 可创建包含多个角度的生成批次。
- 只有工程师确认的图片会出现在客户预览中。
- 分享链接可以停用，并可设置有效期。
- 所有效果预览清楚展示 AI 标识和免责声明。
- 客户无法读取其他项目、原始资料或工程师内部信息。

## 12. 后续阶段

### 阶段一：内容与原型确认

- 确认产品方案和页面结构
- 准备店铺资料、业务文案和真实案例
- 明确工程师常用材料、材质和颜色选项
- 用真实项目样本验证 AI 生图可行性

### 阶段二：首版开发

- 建立小程序和云开发环境
- 完成公共展示、工程师工作台和分享预览
- 接入首个 AI 生图服务
- 完成权限、审核和免责声明机制

### 阶段三：试运行

- 选择 3–5 个真实项目试用
- 统计生成成功率、重试次数和客户反馈
- 优化工程师录入模板和提示词结构

### 阶段四：能力扩展

- AI 效果视频
- 常用材料与产品模板库
- 项目版本对比
- 访问数据和获客转化分析
