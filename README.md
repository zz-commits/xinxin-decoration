## 本轮开发：结构方案与生成前确认

- 安装位置可录入最多 6 个安装面，每面最多 12 个分格，分别记录尺寸、转角关系、开启方式 / 方向与避让要求。

- 服务端重新核对当前方案和资料摘要，拒绝过时确认；结构变更也会阻止旧图创建新分享、旧失败任务重新生成。
- 旧纯文字方案保持兼容；未增加结构扩展时，原有要求哈希不变。
- [领域术语](./CONTEXT.md) 区分“安装面”和“观察角度”、“方案确认”和“效果图审核”。

## 本地验证

```sh
npm ci
npm run sync:domain
npm run build:content
npm run typecheck
npm test
npm run check
```

`build:content` 从 `miniprogram/data/catalogue.json` 生成小程序脚本模块和云端 JSONL 初始数据；不要直接编辑生成文件。`check` 在安装了微信开发者工具的 macOS 上额外执行原生 WXML / WXSS 编译；其他环境会明确跳过原生编译。

结构方案规则的唯一源文件是 `shared/structure-plan.js`。修改后执行 `npm run sync:domain`，同步到独立部署的工程师函数、Worker 和小程序；`check` 会拒绝未同步的副本。
